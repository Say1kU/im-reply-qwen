# Profile LoRA 固定评测

评测日期：2026-08-19

## 设置

- 基础模型：Qwen3-0.6B；
- 训练数据：96 条合成招聘沟通样例，3 轮、36 步；
- 测试数据：16 条未参与训练的固定样例；
- LoRA：rank 8、alpha 32、all-linear、BF16；
- 设备：NVIDIA GeForce RTX 4060 Laptop GPU；
- 自动指标：长度、目标关键词、禁用表述、思考泄漏和显式事实冲突。

## 结果

| 模型 | 规则全通过率 | 目标信息通过率 | 显式事实一致率 | 平均延迟 |
|---|---:|---:|---:|---:|
| 原始 Qwen3-0.6B | 68.75% | 75.00% | 100.00% | 0.801 秒 |
| 旧 3-step LoRA | 87.50% | 87.50% | 100.00% | 1.689 秒 |
| Profile checkpoint-12 | **93.75%** | **93.75%** | 100.00% | 1.355 秒 |
| Profile checkpoint-24 | 87.50% | 87.50% | 100.00% | **1.300 秒** |
| Profile checkpoint-36 | **93.75%** | **93.75%** | 100.00% | 1.364 秒 |

Demo 默认选用 checkpoint-36。checkpoint-12 与它的通过率相同，但在生产部署状态问题上生成了
“正在部署，已经完成”的自相矛盾表述；checkpoint-36 的失败回答是“目前没有部署到生产环境，
我正在测试中”，风险更低。

完整逐条输出和分数见 `reports/profile-eval.json`。

## Demo 默认问题实测

问题为“确认投递大模型岗位，并简要说明匹配经历”，输入六条公开技能事实：

- 原始模型：`确认投递岗位，匹配经历。`
- Profile LoRA checkpoint-36：`您好，我投递的是大模型岗位，使用 Python、Streamlit 和大模型 API 开发过，也实现过简历解析项目。`

新版 LoRA 在相同提示下引用了可验证的真实经历，目标信息检查由失败变为通过。

## 结论与限制

这次训练把固定规则通过率从 68.75% 提高到 93.75%，证明 LoRA 对目标回复格式和真实经历引用
产生了可测提升。但 16 条测试集很小，关键词规则也不能代替语义判断。发布前仍需扩大独立测试集，
并进行不知道模型名称的人工盲评。当前结果不能描述为生产级效果。

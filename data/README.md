# 数据说明

`seed_train.jsonl` 是用于打通训练流程的人工编写种子数据，不应直接被描述为完整训练集。
公开版本建议扩展到 800～1500 条，并对每条回复进行人工复核。

`eval.jsonl` 是独立评测集。扩展数据时，应按场景模板或事件拆分训练集和测试集，避免把
只改了人物名、时间或数字的近重复样本分到两边。

隐私规则：

- 不使用真实聊天、简历、手机号、邮箱、订单号或公司内部资料。
- 示例中的姓名、编号、公司和时间均为虚构。
- 使用模型辅助生成时，在数据卡中披露生成模型、提示词版本和人工清洗过程。

代码使用 MIT 许可证。最终公开数据集前，请单独选择并附上数据许可证（建议 CC BY 4.0），
同时确认所有数据来源允许再发布。
